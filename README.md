# Interactive Information Visualization Course

This repository contains a collection of assignments and visualization projects developed as part of the **Interactive Information Visualization** course at TU Dresden. The coursework explores the design and implementation of interactive visualizations, covering different visualization techniques, interaction methods, and display environments.

## Repository Structure

The repository contains the following assignments:

1. **Assignment 1 — Visualization Design:** Exploring data mappings, visual variables, interaction concepts, and interface designs through sketching and the Five Design Sheet (FDS) methodology.

2. **Assignment 2 — Visualization Tools:** Creating and comparing data visualizations using different visualization tools and techniques.

3. **Assignment 3 — Multivariate & Network Visualization:** Interactive exploration of multidimensional data using Parallel Coordinates, Scatterplot Matrices, and Force-Directed Network Graphs with coordinated interactions.

4. **Assignment 4 — Semantic Zoom & Magic Lenses:** Exploring focus+context techniques through semantic zooming, detail lenses, edge highlighting, and fisheye distortion in network visualizations.

5. **Assignment 5 — Immersive & Large-Display Visualization:** Designing interactive visualization concepts for large displays and head-mounted displays, with emphasis on input, output, and multi-user interaction.

Each assignment directory contains its own README with a more detailed description of the task, approach, and final results.

## Technologies & Methods

The coursework combines implementation and visualization design using:

- D3.js
- JavaScript
- HTML / CSS
- Cytoscape.js
- Bootstrap
- Interactive visualization techniques
- Visual encoding and data mapping
- Coordinated multiple views
- Semantic zoom and focus+context techniques
- Visualization sketching and prototyping
- Immersive and large-display visualization design

## Running the Interactive Projects

Some assignments are conceptual design projects and do not require execution.

For implemented web-based visualizations, navigate to the corresponding assignment directory and follow the instructions in its README.
