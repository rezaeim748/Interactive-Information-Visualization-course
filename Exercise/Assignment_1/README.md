# Information Visualization — Visualization Design

A visualization design project developed for the **Interactive Information
Visualization** course at TU Dresden.

The goal of the assignment was to explore different ways of mapping
multidimensional data to effective visual representations. The project focuses
on the design process rather than implementation, using hand-drawn sketches
to experiment with visualization techniques, visual variables, interaction
ideas, and interface layouts.

## Design Process

The designs were developed using the **Five Design Sheet (FDS)** approach:

1. **Brainstorming** — generating and comparing multiple visualization ideas.
2. **Initial Designs** — refining selected ideas and considering layout,
   interactions, and visual mappings.
3. **Realization Design** — developing the selected concept in greater detail.

## Topics Explored

- Data-to-visual-variable mapping
- Multivariate data visualization
- Visualization and interface design
- Interaction concepts
- Visual encoding and perception
- Five Design Sheet (FDS) methodology
