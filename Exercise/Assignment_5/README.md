# Immersive & Large-Display Visualization Design

A conceptual visualization design project developed for the **Interactive
Information Visualization** course at TU Dresden.

The project explores how interactive data visualizations can be designed for
different display environments in a museum setting. Two visualization
installations were designed: one for a **large interactive wall display** and
one for **head-mounted displays (HMDs)**.

## Installation Concepts

### Large Interactive Display

A visualization installation designed for an approximately 8 × 3 meter
interactive display, exploring how visitors can interact with information
individually and collaboratively in a shared physical space.

### Immersive Visualization

A second installation designed for wireless head-mounted displays, exploring
how data visualization can make use of immersive and spatial interaction.

## Design Considerations

The concepts were analyzed from three main perspectives:

- **Output** — how information is visually presented
- **Input** — how users interact with and manipulate the visualization
- **Multi-user interaction** — how multiple visitors can experience and
  interact with the installation

The project also compares the opportunities and constraints of large-display
and immersive visualization environments.
